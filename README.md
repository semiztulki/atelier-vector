# Ателье — векторный редактор

Универсальное браузерное приложение для правки готовых векторных макетов. Проект не привязан к бейджам, блокнотам или сертификатам. Все инструменты работают с любым поддерживаемым документом.

## Запуск

GitHub Pages публикует ветку `main`, папку `/ (root)`. Корневой `index.html` ссылается на ресурсы в `dist/`; он пересоздаётся командой `npm run vendor`. Установка для пользователя не нужна. Выбранные файлы обрабатываются локально в браузере; сервер приложения их не получает.

## Возможности первой версии

- Открытие SVG, PDF и AI с включённой PDF-совместимостью, все страницы документа.
- Выделение, рамка выделения, Shift для нескольких объектов, перемещение, масштабирование и поворот.
- Положение и размер в миллиметрах, размеры страницы, отдельная индикация TrimBox импортированного PDF.
- Текст с переносами строк, шрифт, размер, межстрочное расстояние и выравнивание; загрузка TTF/OTF.
- Прямоугольник, эллипс, линия, ломаная, редактирование узлов и ручек кривых.
- Направляющие, сетка, привязка к краям и центрам объектов и страницы, временное отключение через Alt.
- Выравнивание относительно выделения, страницы или последнего выбранного объекта; равные промежутки.
- Список объектов, скрытие, блокировка, порядок наложения, группировка объектов в одном контейнере.
- Векторные QR-коды, отмена/повтор, копирование, сохранение `.atelier`, автосохранение в этом браузере.
- Экспорт SVG, векторного многостраничного PDF и PNG (300 dpi по физическому размеру).

## Ограничения

Это прототип для испытаний, не готовый препресс-редактор. При импорте PDF/AI используются RGB-представления цветов. Pantone/Separation, наложение красок, структура исходных слоёв Illustrator и производственные свойства тиснения/вырезки не сохраняются. Экспорт не является PDF/X. AI без PDF-представления не читается; AI и CDR пока не экспортируются.

Текст, переведённый в кривые, остаётся контурами. Подмножества встроенных PDF-шрифтов сохраняют исходный внешний вид; для изменения строки нужен полный шрифт. При редактировании импортированного текста создаётся новый текстовый объект с выбранным полным шрифтом. Сложная исходная типографика может потребовать ручной настройки. Пользовательский полный шрифт включается в файл проекта — следует использовать шрифты с подходящими правами.

PDF экспортирует текст как векторные контуры. Для неизвестных системных шрифтов используется Atelier Sans с уведомлением. В SVG можно оставить редактируемый текст. PDF сохраняет физический размер страницы и TrimBox. В диалоге печати следует выбрать 100% / фактический размер. Измерительная шкала внутри макета требует самостоятельной проверки — размер страницы не подтверждает правильность делений.

Сложные маски и нестандартные PDF-операции могут импортироваться с отличиями; SVG-бэкенд PDF.js экспериментальный. Исходный файл следует сохранять отдельно. Группировка между разными импортированными контейнерами пока ограничена.

## Разработка

```sh
npm ci
npm run vendor
npm run check
npm test
```

Статические файлы находятся в `dist/`; любая статическая HTTP-раздача этой папки пригодна для локальной разработки. Изменения зависимостей требуют повторного `npm run vendor`. Все зависимости поставляются вместе с приложением; CDN не используется.

В PDF.js отключён `isEvalSupported`; импортируемый SVG очищается DOMPurify. PDF.js 3.x закреплён ради SVG-бэкенда; перед расширением поддержки произвольных PDF необходимо заменить этот устаревший экспериментальный путь на поддерживаемый импортёр. Персональные исходные макеты не включаются в репозиторий.

## Дальнейшая работа

- Сохранение CMYK, плашечных цветов и технических слоёв; проверяемый PDF/X.
- Улучшение восстановления текстовых блоков, поворота и типографики при импорте PDF.
- Полноценная работа с группами и масками импортированных документов.
- Равномерное размещение текстовых объектов в заданном числе колонок.
- Экспорт AI/CDR через отдельно проверенный путь конвертации.
